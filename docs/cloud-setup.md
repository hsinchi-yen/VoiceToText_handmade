# 串接雲端服務

v2c 預設**全部使用地端模型**：語音辨識用你電腦上的 Breeze-ASR-25／SenseVoice，潤飾與中翻英用 LM Studio。不需要任何 API 金鑰就能使用。

如果你想讓辨識更快、潤飾更好，或電腦沒有足夠的顯示卡，可以把某些用途交給雲端服務。這是**選用**的。

> **費用與隱私**
> 雲端服務會依用量向你收費，錄音或文字會上傳到該服務。
> 只有你勾選的用途會送到雲端；沒勾的仍然在你的電腦上處理。

## 支援的服務

| 服務 | 語音辨識 | 潤飾 | 中翻英 | 需要金鑰 |
|------|:--:|:--:|:--:|:--:|
| Google Gemini | ✓ | ✓ | ✓ | 需要 |
| OpenAI | ✓ | ✓ | ✓ | 需要 |
| Anthropic Claude | — | ✓ | ✓ | 需要 |
| 自訂相容端點（OpenAI 相容，例如別台電腦的 LM Studio、自架服務） | 依端點 | ✓ | ✓ | 選填 |

Claude 不接受錄音，**只能潤飾與中翻英**。

## 精靈的 7 個步驟

打開 v2c 主視窗 → 上方「雲端服務」→「新增雲端服務」。

<!-- 圖：雲端服務列表與「新增雲端服務」按鈕 -->

### 1. 選擇服務

點選 Gemini、OpenAI、Claude 或「自訂相容端點」。每個選項下方會寫出它能做的用途。

### 2. 取得金鑰

精靈會列出取得金鑰的步驟，並提供「用瀏覽器開啟官方金鑰頁面」按鈕。各家的做法見下方〈各家取得金鑰的方法〉。

自訂相容端點則在這一步填入**端點網址**（base_url），例如 `http://192.168.1.20:1234/v1`。

### 3. 貼上金鑰

把金鑰貼進欄位。金鑰會存進 **Windows 認證管理員**（不會寫進設定檔），畫面上只顯示**末 4 碼**。

自訂相容端點若不需要金鑰，留空即可。

### 4. 選擇模型

精靈會預先填好建議的模型。若服務提供模型清單，欄位會出現下拉選單讓你挑；也可以直接輸入模型名稱。

- 語音辨識模型：Claude 沒有這一欄。
- 文字模型：用於潤飾與中翻英。

### 5. 測試連線

按「開始測試」。語音辨識會送出一段內建的 3 秒測試音檔（不是你的聲音），文字模型會送出一句測試文字。結果會顯示每一項是否通過與延遲（毫秒）。

失敗時會用白話說明原因，對照下方〈疑難排解〉。

<!-- 圖：測試連線結果 -->

### 6. 指定用途

勾選要交給這個服務的用途：語音辨識／潤飾／中翻英。**沒勾的維持地端**。測試沒通過的用途無法勾選。

按「儲存」。

### 7. 完成

設定立刻寫入。之後想全部切回地端，見〈切回地端〉。

## 各家取得金鑰的方法

以下網址於 2026 年 11 月確認。

### Google Gemini

1. 開啟 Google AI Studio 的金鑰頁面：<https://aistudio.google.com/apikey>，用 Google 帳號登入。
2. 按「Create API key」（如果沒看到你的 Google Cloud 專案，先在 Dashboard 的 Projects 匯入）。
3. 複製金鑰（通常以 `AIza` 開頭），貼到精靈第 3 步。

Gemini 有免費額度，超過後依用量計費；免費方案的資料可能被用於改善服務，在意的話請改用付費方案。

### OpenAI

1. 開啟 <https://platform.openai.com/api-keys> 並登入。OpenAI API 和 ChatGPT 訂閱是**分開計費**的。
2. 先到 Billing（<https://platform.openai.com/account/billing/overview>）儲值，否則金鑰呼叫會失敗（顯示「額度不足或請求太頻繁」）。
3. 按「Create new secret key」，複製金鑰（以 `sk-` 開頭，**只會顯示一次**）。

### Anthropic Claude

1. 開啟 Claude Console 的金鑰頁面：<https://platform.claude.com/settings/keys> 並登入。
2. 先在 Billing（<https://platform.claude.com/settings/billing>）儲值。
3. 按「Create Key」，複製金鑰（以 `sk-ant-` 開頭，**只會顯示一次**）。

Claude 只能用於潤飾與中翻英；語音辨識請維持地端或交給另一個服務。

### 自訂相容端點（例如別台電腦的 LM Studio）

1. 在那台電腦的 LM Studio「Developer」頁啟動伺服器，並在伺服器設定開啟「Serve on Local Network」。
2. 端點網址填 `http://那台電腦的IP:1234/v1`（要包含 `/v1`）。
3. 若你的服務需要金鑰才貼上；LM Studio 預設不需要。
4. 模型名稱填該伺服器上的模型 ID。大多數 LM Studio 模型只能潤飾與中翻英；語音辨識需要端點支援 `/audio/transcriptions`。

官方服務（Gemini／OpenAI／Claude）的網址必須是 `https://`；`http://` 只允許自訂相容端點或本機（localhost）。

## 管理已串接的服務

「雲端服務」頁會列出每個服務：用途、模型、金鑰末 4 碼。

- **測試連線**：用目前設定重新測試。
- **修改**：官方服務（Gemini／OpenAI／Claude）從第 3 步開始，可改金鑰、模型、用途；自訂相容端點從第 2 步開始，可以改端點網址。金鑰欄留空就沿用已儲存的金鑰，但**改了端點網址就必須重新貼上金鑰**（自訂端點若不需要金鑰可留空，舊金鑰會被刪除），避免舊金鑰被送到新的網址。
- **移除**：刪除服務與 Windows 認證管理員裡的金鑰，原本交給它的用途自動改回地端。若畫面提示金鑰沒能刪除，v2c 已不會再使用它，可以自行到認證管理員刪除。

## 切回地端

- **一鍵全部切回**：在系統列的 v2c 圖示按右鍵 →「全部改用地端」，立即生效。服務與金鑰會保留，之後可在「修改」重新勾選用途。
- **只停用某個用途**：「修改」→ 第 6 步取消勾選。
- **完全移除**：「移除」。

另外，設定 `cloud_fallback_to_local = true`（預設）時，雲端呼叫失敗會自動改用地端。

## 疑難排解（依畫面上的訊息）

| 訊息 | 原因與處理 |
|------|-----------|
| 金鑰錯誤（或這把金鑰沒有權限） | 金鑰貼錯、多貼了空白、已被撤銷，或專案沒有權限。回到第 3 步重新貼上；必要時到官方頁面重新建立金鑰。 |
| 額度不足或請求太頻繁 | 帳戶沒有儲值、額度用完，或短時間內請求太多。到該服務的 Billing 頁確認，或稍後再試。 |
| 網路不通（連不到這個服務） | 電腦沒有網路、公司防火牆擋住，或自訂端點的電腦沒開機、LM Studio 伺服器沒啟動、IP 填錯。 |
| 這個端點不支援語音辨識 | 自訂端點沒有 `/audio/transcriptions`（例如 LM Studio）。語音辨識維持地端，只把潤飾／中翻英交給它。 |
| 這個端點不支援文字模型（請確認模型名稱） | 端點沒有 `/chat/completions`，或網址少了 `/v1`。 |
| 伺服器錯誤，請稍後再試 | 服務暫時故障，稍後再試。 |
| 服務回應無法辨認（請確認網址與模型名稱） | 模型名稱打錯或該模型不存在、網址指到別的服務。回第 4 步改用建議模型或下拉清單中的模型。 |
| 逾時：服務回應太慢 | 網路慢或服務忙碌。可在 `config.toml` 的 `[timeouts]` 調整 `asr_cloud_ms`、`llm_cloud_ms`。 |
| 這個服務沒有提供模型清單（不影響使用） | 自訂端點沒有 `/models`，請自行輸入模型名稱。 |
| 端點網址不正確：官方服務必須是 https:// 開頭 | 自訂的官方服務網址必須用 https。 |
| 無法存取 Windows 認證管理員（金鑰庫） | 重新啟動 v2c；若仍失敗，確認 Windows 帳戶可以使用「認證管理員」。 |
| 設定檔 config.toml 格式有誤，請先修正 | 你手動改過的 `%APPDATA%\v2c\config.toml` 有語法錯誤。v2c 不會覆寫它；修正後再試。 |

## 金鑰存在哪裡

- 金鑰存在 Windows 認證管理員（控制台 → 認證管理員 → Windows 認證），項目名稱包含服務代號與 `v2c`（例如 `gemini.v2c`）。
- `config.toml` 只記錄服務種類、網址、模型名稱與用途，不含金鑰。
- v2c 的紀錄檔不會寫入金鑰、辨識結果或潤飾後的文字。
