## 卡片格式

```
# T<id> <標題>
- 波次 / 前置：
- 目標：一句話
- 先讀：文件章節連結（不複製內容）
- 允許修改：路徑清單（以外的檔案不准動）
- 對外介面：本任務提供或依賴的型別/函式；不得變更 v2c-core 公開介面（要改先停下請示）
- 實作重點：
- 驗收：
- 驗證指令：
- 🧑 需人工：
- 合併：自動 ／ 需你核准
```
