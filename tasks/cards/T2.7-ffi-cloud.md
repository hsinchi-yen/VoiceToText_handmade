# T2.7 FFI 雲端服務

- 波次 / 前置：W10c ／ T2.3、T2.4（皆已合併）
- 分派：實作 Sonnet（worktree，分支 `t2.7-ffi-cloud`）→ 測試 Haiku → 審查 Opus → 主 agent 決定（見 `README.md`〈分派流程〉）
- 目標：讓 Android 透過 FFI 使用使用者設定的雲端服務做語音辨識與中翻英，並把「雲端」排進 `choose_asr` 的路由（2026-11-13 你決定：自動順序為 區網 → 雲端 → 手機本地）。
- 先讀：`tasks/plan.md` 第 8.1 節（新路由表）、第 8.3 節、第 6 節（provider 表與雲端 HTTP 規則）；`v2cplan.md` 第 3 節 Android 各列；`crates/v2c-ffi/src/{lib.rs,route.rs,services.rs}`；`crates/v2c-core/src/{asr,llm,config.rs}`
- 允許修改：`crates/v2c-ffi/**`、`crates/v2c-ffi/ANDROID.md`、`tasks/todo.md`
- 對外介面（FFI，同步，沿用 T2.3 的內部 tokio runtime）：
  - `set_cloud_services(services: Vec<CloudServiceConfig>, keys: HashMap<String, String>)`：`CloudServiceConfig` 含 `id`、`provider`（gemini／openai／claude／custom）、`model`、`asr_model`（選填）、`base_url`（custom 必填）、`uses`（asr／translate）；轉成 `v2c-core` 的 `CloudService` 放進和 `load_lan_services` 同一個註冊表（取代上一次的雲端設定，不動區網項目）。金鑰只留在記憶體。
  - `transcribe_pcm`／`translate` 的 `service_id` 接受雲端代號；Claude 做辨識回錯誤碼 `Unsupported`。
  - `test_connection(service_id, purpose) -> TestResult`：辨識送內建的短測試音（產生的靜音＋音調即可，不用使用者錄音），翻譯送固定測試句；回延遲毫秒或錯誤碼（金鑰錯誤、額度不足、網路不通、端點不支援音訊、逾時）。
  - `choose_asr(lan, cloud_ready, system_available, local_model_ready, pick)`：新增 `cloud_ready` 參數與 `AsrSource::Cloud`／`pick = Cloud`。
- 實作重點：
  - 沿用 `v2c-core` 現有 Gemini／OpenAI／Claude／相容端點 provider；不改 `v2c-core` 公開介面。若非改不可，停下回報並請你核准。
  - 雲端一律 HTTPS（loopback 除外）、不跟隨轉址；使用 `CloudService` 的逾時（辨識 `asr_timeout_ms` 或預設 ASR 逾時；翻譯沿用 `TRANSLATE_TIMEOUT_MS`）。
  - 錯誤只回錯誤碼；不含金鑰、辨識文字、翻譯文字。
- 驗收：
  - `cargo test -p v2c-ffi` 涵蓋 `tasks/plan.md` 第 8.1 節新路由表每一列，含「區網失敗 → 雲端 → 本機」、「強制雲端但沒設定時回提示、不靜默改用別的」。
  - `set_cloud_services` 的測試：取代舊設定、不影響區網服務、custom 缺 base_url 回錯、http（非 loopback）被拒。
  - `transcribe_pcm`／`translate`／`test_connection` 用本機假 HTTP 伺服器測各 provider 的成功與錯誤碼對應（不打真的雲端）。
  - `ANDROID.md` 記下新增的 Kotlin 呼叫方式。
- 驗證指令：`cargo test -p v2c-ffi`；`cargo clippy -p v2c-ffi --all-targets -- -D warnings`；`cargo fmt --all --check`；`cd apps/android && ./gradlew assembleDebug`（確認 Kotlin 綁定可編譯；Kotlin 端還沒呼叫新函式時，只需舊呼叫照常編譯——`choose_asr` 簽名改變時，同步修 `apps/android/app/src/main/java/**/ffi/**` 的呼叫點，這個目錄也允許修改）
- 🧑 需人工：無
- 合併：需你核准（變更 FFI 對外介面）
