# T2.1 Android 語音鍵盤最小路徑

- 波次 / 前置：W8 ／ T2.0
- 分派：實作 Sonnet（worktree，分支 `t2.1-android-ime`）→ 測試 Haiku → 審查 Opus → 主 agent 決定合併或退回（見 `README.md`〈分派流程〉）
- 目標：建立 Gradle 專案與 Kotlin IME：Typeless 式大麥克風 → `SpeechRecognizer`（zh-TW）→ `commitText`；首次啟動引導（授權麥克風、啟用並切換到 v2c 鍵盤）。系統辨識是 `tasks/plan.md` 第 8.1 節三個辨識來源之一，區網與本機模型留給 T2.4／T2.6。
- 先讀：`tasks/plan.md` 第 8 節（範圍、鍵盤按鍵、操作風格、版本與建置、8.1）；`v2cplan.md` 第 3、4 節（Android 各列）
- 允許修改：`apps/android/**`（建立 Gradle 專案），但 `apps/android/app/src/main/java/**/ffi/` 留給 T2.3；`tasks/todo.md`
- 對外介面：`V2cImeService`、`KeyboardView`（Compose）、`SetupActivity`（唯一的 Activity）
- 實作重點：
  - 環境：`ANDROID_HOME` 已設；SDK 有 platform `android-36`、`android-37.0`，build-tools 36.0.0，NDK 28.2；`JAVA_HOME` 是 JDK 17。用 Gradle wrapper，不安裝系統軟體。
  - 【實作前確認】`compileSdk`／`targetSdk` 36～37 可用的穩定版 AGP、Kotlin 2.x（Compose Compiler Gradle plugin）、Compose BOM 的相容組合（JDK 17 可用者）；版本集中在 `gradle/libs.versions.toml`；`minSdk` 28。報告中寫明查證結果。
  - `ComposeView` 要設定 `ViewTreeLifecycleOwner` 與 `SavedStateRegistryOwner`；處理 edge-to-edge insets（手勢列）。
  - 操作：點一下開始、再點一下結束並送出；按住超過約 300 ms 為按住說話、放開送出。狀態：待命 → 錄音（波形＋計時）→ 辨識中 → 完成（直接 `commitText`）。不顯示部分結果或辨識中的文字。點擊／按住的判斷寫成純 Kotlin 類別並有單元測試。
  - API 31+ 優先 `createOnDeviceSpeechRecognizer`；`isRecognitionAvailable()` 為 false 時顯示安裝 Google 語音服務的提示。
  - 版面預留：中翻英鍵、退格、換行、辨識來源小圖示的位置（行為由 T2.2、T2.4 實作）。沒有設定頁。
  - 不記錄辨識文字（Logcat 也不行）。
- 驗收：`assembleDebug`、`lint`、`testDebugUnitTest` 通過；在 Android 16／17 手機上，LINE、Chrome 點一下麥克風說中文、英文、夾雜句子，再點一下後文字出現；按住說話也可用。
- 驗證指令：`cd apps/android && ./gradlew assembleDebug lint testDebugUnitTest`
- 🧑 需人工：側載到你的手機實測；回報手機型號與 Android 版本。
- 合併：需你核准（含 🧑）
