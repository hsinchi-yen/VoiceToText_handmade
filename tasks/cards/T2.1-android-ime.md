# T2.1 Android 語音鍵盤最小路徑

- 波次 / 前置：W8 ／ 檢查點 1
- 目標：Kotlin IME：按住麥克風鍵 → `SpeechRecognizer`（zh-TW）→ `commitText`。
- 先讀：`tasks/plan.md` 第 8 節；`v2cplan.md` 第 3、4 節（Android）
- 允許修改：`apps/android/**`（建立 Gradle 專案），但 `apps/android/app/src/main/java/**/ffi/` 留給 T2.3
- 對外介面：`V2cImeService`、`KeyboardView`（Compose）、`SetupActivity`（授權麥克風、引導啟用鍵盤）
- 實作重點：`ComposeView` 要設定 `ViewTreeLifecycleOwner` 與 `SavedStateRegistryOwner`；API 31+ 優先使用 `createOnDeviceSpeechRecognizer`；`isRecognitionAvailable()` 為 false 時顯示安裝 Google 語音服務的提示（雲端備援留給 T2.4）；最低 API 28。
- 驗收：在 LINE、Chrome 按住麥克風輸入中文、英文、夾雜句子；部分結果顯示在鍵盤上方的預覽列。
- 驗證指令：`cd apps/android && ./gradlew assembleDebug lint`
- 🧑 需人工：側載到你的手機實測；回報手機型號與 Android 版本。
- 合併：需你核准（含 🧑）
