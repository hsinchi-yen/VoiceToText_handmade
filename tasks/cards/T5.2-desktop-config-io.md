# T5.2 桌面組態檔匯出／匯入（Windows＋Linux）

- 波次 / 前置：W23 ／ T5.1
- 分派：實作 Sonnet（worktree，分支 `t5.2-desktop-config-io`）→ 測試 Haiku → 審查 Opus → 主 agent 決定（見 `README.md`〈分派流程〉）
- 目標：桌面版設定頁可以匯出、匯入組態檔；Windows 與 Linux 是同一份 Tauri 程式，兩邊都要能用。
- 先讀：`tasks/plan.md` 第 14 節、第 13.1 節；`docs/config-file.md`；`crates/v2c-core/src/portable.rs`；`apps/desktop/src-tauri/src/commands/{presets.rs,settings.rs,vocab.rs}`、`config_edit.rs`；`apps/desktop/ui/presets/PresetDialog.svelte`、`ui/routes/Settings.svelte`
- 允許修改：`apps/desktop/src-tauri/src/commands/{presets.rs,mod.rs}`、新增 `apps/desktop/src-tauri/src/commands/config_io.rs`、`apps/desktop/src-tauri/src/main.rs`（只限註冊指令與 plugin）、`apps/desktop/src-tauri/{Cargo.toml,capabilities/**,tauri.conf.json}`（只限 dialog plugin）、`apps/desktop/ui/**`（設定頁、預覽對話框、首頁「從檔案載入」入口）、`apps/desktop/package.json`、`docs/cloud-setup.md`（加一節「匯出與匯入設定」並連到 `docs/config-file.md`）、`tasks/todo.md`、`tasks/human-checklist.md`
- 實作重點：
  - `presets.rs` 的驗證與合併改用 `v2c_core::portable`；內建 TN／RD 套用行為不變（現有測試不改期望值）。
  - 指令：`config_export(path)`、`config_import_preview(path)`、`config_import_apply(path, keys)`；套用沿用金鑰選擇順序、主機改變刪舊金鑰、`CONFIG_LOCK`＋toml_edit 原子寫入、失敗還原金鑰、寫完發 `v2c:config-changed`；詞庫用 `Vocab::save` 寫入，與 `config.toml` 一起成功或一起還原。
  - 介面：設定頁底部（「重新執行初次設定」上方）「匯出設定」「匯入設定」；匯入預覽列出新增／更新／不變的服務、route 變更、詞庫新增數、被忽略的區段、需要貼的金鑰。匯出時提示「檔案不含金鑰，但含詞庫，分享前請確認」。
  - 檔案對話框：Tauri dialog plugin（【實作前確認】版本與 Linux xdg-desktop-portal 行為，記在報告）。
  - 日誌只記：檔名長度或「使用者選的檔案」、服務數、詞庫數量、錯誤碼、耗時。
- 驗收：
  - Rust 測試：匯出後再匯入＝全部不變；用 `tests/fixtures/config/` 的檔案測預覽與套用；寫入失敗時 `config.toml`、詞庫、金鑰都還原；內建預設檔測試照舊通過。
  - `npm run check`、`npm test` 通過（純 JS 部分加預覽資料轉換的測試）。
- 驗證指令：`cargo test --workspace`；`cargo clippy --workspace --all-targets -- -D warnings`；`cargo fmt --all --check`；`cd apps/desktop && npm run check && npm test && npm run build`
- 🧑 需人工：Windows 安裝版上匯出→刪掉一個服務→匯入，確認服務回來、金鑰提示正確；Linux（GNOME Wayland）上同樣操作一次，確認檔案對話框能開（見 `linux_handover.md`）。
