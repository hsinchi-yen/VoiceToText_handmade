# T3.5 IBus 輸入法引擎（Linux 熱鍵＋輸出）

- 波次 / 前置：W15 ／ T3.1～T3.4（已合併）
- 目標：v2c 以 IBus 引擎身分接收焦點輸入框的按鍵（按住右 Ctrl 說話），並以 `CommitText` 直接輸出中文。
- 先讀：`v2cplan.md` 第 2 節「桌面整合」；`tasks/plan.md` 第 3、4 節、第 9.2a 節；`crates/v2c-platform/src/linux/{hotkey,inject}.rs`
- 允許修改：`crates/v2c-platform/src/linux/ibus/*.rs`、`crates/v2c-platform/src/linux/mod.rs`、`crates/v2c-platform/Cargo.toml`（Linux 依賴）、`crates/v2c-platform/src/lib.rs`（只加錯誤變體）、`tools/ibus/v2c.xml`、`tasks/todo.md`
- 對外介面：`linux::ibus::{IbusAddress, IbusEngine, IbusHotkey（實作 Hotkey）, IbusInjector（實作 Injector）}`；不改 `v2c-core`
- 實作重點：
  - 連線：依 IBus 規則找位址（`IBUS_ADDRESS`，否則 `~/.config/ibus/bus/<machine-id>-<host>-<display>`），用 zbus 連到 IBus 私有 bus。
  - Factory／Engine 物件：`CreateEngine` → 匯出 Engine；處理 `ProcessKeyEvent`、`FocusIn/Out`、`Reset`、`Enable/Disable`。右 Ctrl（`Control_R` 0xffe4）、Shift、Esc 轉成 `trigger::Event`；觸發鍵本身回傳 true（吞掉），其他鍵回傳 false 放行。
  - 輸出：`Text`／`Paste` → `CommitText(IBusText)`；`NewLine` → `ForwardKeyEvent(Return, Shift?)`。
  - 日誌不得含文字；`IBusText` 只在記憶體組裝。
  - 【實作前確認】ibus 1.5.26 原始碼的 D-Bus 介面、`IBusText`／`IBusAttrList` 序列化（`(sa{sv}sv)`）、`RegisterComponent` 參數。
- 驗收（mock）：keyval／state（含 `IBUS_RELEASE_MASK`）→ Event 的轉換表；序列餵進 `trigger::Trigger`（按住說話、雙擊免持、Ctrl+C 取消、Shift 翻譯、Esc）；`IBusText` 序列化位元組；注入動作 → 訊號序列。
- 驗收（本機真實，`#[ignore]`，名稱含 `ibus_real`，**需你同意後才執行**）：在你的 ibus-daemon 上動態註冊暫時的 `v2c-test` 引擎，再用測試客戶端（`CreateInputContext` → `FocusIn` → `SetEngine`）送合成按鍵，確認收到 `CommitText` 的中文與換行；結束時登出並移除，不改 GNOME 的輸入來源設定。
- 驗證指令：`cargo test -p v2c-platform`；`cargo test -p v2c-platform -- --ignored ibus_real --test-threads=1`
- 🧑 需人工：在 GNOME 設定加入 v2c 輸入來源，在 gedit／Firefox／終端機實機按住右 Ctrl 說話。
- 合併：需你核准（含 🧑）
