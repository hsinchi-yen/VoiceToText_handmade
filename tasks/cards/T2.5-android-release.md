# T2.5 Android release APK 與安裝說明

- 波次 / 前置：W10b ／ T2.2、T2.4
- 分派：實作 Sonnet（worktree，分支 `t2.5-android-release`）→ 測試 Haiku → 審查 Opus → 主 agent 決定（見 `README.md`〈分派流程〉）
- 目標：可側載的 release APK 與繁中安裝說明。2026-11-12 你決定 Android 只有語音輸入與中翻英，所以**沒有設定頁**（取代原本的設定頁、串接雲端精靈、Keystore 金鑰）。
- 先讀：`tasks/plan.md` 第 8 節；`AGENTS.md` 規則 5（交付物放 `releases/`）
- 允許修改：`apps/android/app/build.gradle.kts` 的簽署與 release 設定、`tools/build-android.ps1`（新增）、`docs/android-install.md`（新增）、`README.md` 的 Android 段落、`tasks/todo.md`
- 實作重點：
  - 簽署金鑰不進 git：`keystore.properties` 與 `.jks` 放在 git-ignored 位置，沒有時 `build-android.ps1` 說明如何產生（由你執行 `keytool`）。
  - `tools/build-android.ps1`：建 `.so` → `assembleRelease` → 驗 16 KB 對齊 → 複製到 `releases/v2c_<版本>_android.apk` → 更新 `releases/SHA256SUMS.txt`。
  - `docs/android-install.md`：側載、授權麥克風、啟用鍵盤、用導覽列切換鍵盤、點一下說話、中翻英、長按小圖示切換來源、本機模型下載、需要公司網路的功能。
- 驗收：`releases/` 有 APK 與 SHA-256；安裝後只需授權麥克風與啟用鍵盤即可使用。
- 驗證指令：`pwsh tools/build-android.ps1`；`zipalign -c -P 16 -v 4 releases/v2c_*_android.apk`
- 🧑 需人工：產生簽署金鑰；側載安裝並照 `docs/android-install.md` 操作一遍。
- 合併：需你核准（含 🧑）
