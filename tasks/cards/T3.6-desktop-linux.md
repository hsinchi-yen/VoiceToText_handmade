# T3.6 桌面 App 支援 Linux

- 波次 / 前置：W16 ／ T3.5；🧑 你已安裝 `tools/build-linux.sh --check` 列出的套件
- 目標：`apps/desktop` 能在 Linux 編譯執行：IBus 引擎模式、通知、金鑰庫、紀錄加密、Linux 路徑。
- 先讀：`tasks/plan.md` 第 6、7、9 節；`apps/desktop/src-tauri/src/{main,controller,providers,engine}.rs`、`build.rs`
- 允許修改：`apps/desktop/src-tauri/**`（`cfg(target_os = "linux")` 分支為主，不改 Windows 行為）、`crates/v2c-platform/src/linux/**`、`tasks/todo.md`
- 對外介面：不改 `v2c-core`；需要時先請示
- 實作重點：
  - `build.rs`：Windows 專用 DLL 只在 Windows 處理。
  - 金鑰：安裝 Secret Service 的 keyring-core store。【實作前確認】crate 名稱與版本。
  - 紀錄加密：Linux 以 Secret Service 存的金鑰加密（plan.md 第 7 節）。
  - controller：Linux 用 `IbusHotkey`／`IbusInjector`，引擎未啟用時退回 T3.1／T3.2 的後端並以 T3.4 通知提示；浮動標籤在 Wayland 停用。
  - `[gpu] enabled=false` 為 Linux 預設；Breeze 本機 GPU 路線停用，ASR 走設定的遠端端點或 SenseVoice CPU。
- 驗收：`cargo build -p v2c-desktop`（Linux）、`cargo test --workspace`、clippy、fmt 通過；Windows 程式碼路徑不變（以 `cfg` 隔離）。
- 🧑 需人工：Windows 上重新建置確認沒有回歸。
- 合併：需你核准
