# T1.1 Windows 最小可用路徑

- 波次 / 前置：W2 ／ 檢查點 0
- 目標：按住右 Ctrl 說話 → Breeze 辨識 → 台灣繁體 → 逐字輸出到前景視窗。
- 先讀：`tasks/plan.md` 第 2 節（Pipeline）、第 7 節（controller、recorder）
- 允許修改：`apps/desktop/**`（建立 Tauri v2 骨架與 UI 外殼）、`crates/v2c-core/src/{pipeline.rs,audio.rs,postprocess/zh_tw.rs}`、`tasks/todo.md`
- 對外介面：`controller` 對外發出 `StatusEvent`（Recording{rms} / Transcribing / Polishing / Done / Error）的 broadcast channel，供 T1.3 浮動標籤訂閱；UI 外殼預留路由 `settings`、`vocab`、`history`、`cloud-setup`、`overlay`、`onboarding`（空頁面），以及 `src-tauri/src/commands/` 模組（每個功能一個檔案）；`OutputSink` trait 與 `src-tauri/src/sinks.rs`（註冊輸出完成後要通知的對象，目前為空清單，T1.9 會把輸入紀錄註冊進來，不必改 controller）
- 實作重點：
  - recorder 預設 `always_on`，0.5 秒預錄環形緩衝；裝置變更自動重開。
  - 【實作前確認】`zhconv` 是否支援台灣用語轉換；不行改用 OpenCC 綁定，並更新 `tasks/plan.md`。
  - 太短（< 0.3 秒）或靜音不輸出。
- 驗收：在記事本說中文、英文、夾雜各 3 句皆正確輸出；放開到出字 ≤ 1.5 秒；第一個字不被吃掉。
- 驗證指令：`cargo test --workspace`；`cd apps/desktop && npm run tauri dev`
- 🧑 需人工：實機說話測試並回報延遲（浮動標籤完成前，看日誌中的 `Timings`）。
- 合併：需你核准（含 🧑）
