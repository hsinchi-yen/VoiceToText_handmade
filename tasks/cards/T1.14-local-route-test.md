- 實作重點：
  - **用途選單**：「潤飾與用途」的語音辨識選單，地端拆成「地端：自動（有 NVIDIA 顯示卡用 Breeze，否則 SenseVoice）」「地端：Breeze-ASR-25（NVIDIA 顯示卡）」「地端：SenseVoice-Small（CPU）」，後面接雲端服務。選地端選項時在**同一次** `save` 存 `route_asr = "local"` 與 `local_asr`；選雲端只存 `route_asr`。目前選中的項目：`route.asr` 是雲端 id 就選它，否則選對應 `local.asr` 的地端選項。與「地端語音模型 → 辨識引擎」選單同步（同值同文字）。模型未安裝或此版本沒有 CUDA 時，該選項仍可選但後面標「（未安裝）」或「（此版本無 CUDA）」。
  - **地端語音模型「測試」**：辨識引擎旁的按鈕。用內建測試音（`probe_clip`，約 3 秒）實際跑一次目前設定會用到的地端引擎（依 `select` 規則與 VRAM 狀態），回傳：實際使用的引擎、是否在 GPU、是否因故改用 SenseVoice 及原因（繁中）、載入耗時（若這次才載入）、辨識耗時、Breeze 的 VRAM 用量（若有）。**不回傳也不記錄辨識文字**。正在聽寫時回傳 `busy`，不要搶。
  - **拿掉設定頁的「LM Studio（潤飾與中翻英，選用）」區塊**（2026-11-11 你決定）：位址、模型、測試連線都不再顯示，連帶移除 `settings_test_lm` command、`test_lm` 與其 ACL 項目。`[local] llm_base_url`／`llm_model` 設定與執行邏輯不變（「地端」潤飾／中翻英仍走 config.toml 的 LM Studio，預設 `http://localhost:1234/v1`；雲端失敗仍退回它）。用途選單與說明文字改為「地端（本機 LM Studio）」並提示「要用別台電腦或別的模型，請到雲端服務新增自訂相容端點」。`docs/local-setup.md` 同步說明。
  - **儲存按鈕（暫存模式）**：在 `routes/Settings.svelte` 集中處理，**不改子頁收到的 `save(changes)` 簽名**（仍回傳 true/false），讓 T1.12／T1.13 的子頁修改不受影響。`save` 改為把變更放進待儲存清單並更新畫面上的草稿值，不寫檔。頁面上方固定一列：沒有變更時顯示「所有設定已儲存」；有變更時顯示「有 N 項變更尚未儲存」＋「儲存」＋「取消變更」。按「儲存」一次呼叫 `settings_apply` 送出全部變更；成功顯示「已儲存並套用」，失敗顯示原因並保留草稿。有未儲存變更時離開設定頁（切到其他頁或關視窗）要先詢問。外部改了 config.toml（系統列、雲端服務頁）時，若沒有未儲存變更就重新載入；有的話提示「設定已在別處變更」並讓使用者選擇重新載入或保留草稿。已變更但未儲存的欄位要有明顯標示（例如左側色條或「未儲存」小字）。  - **目前生效中的設定**：設定頁最上方一個區塊「目前使用中」，資料來自引擎的實際狀態（新增一個唯讀 command，例如 `settings_runtime_status`；不是讀設定檔），顯示：語音辨識實際使用的引擎與執行位置（例如「Breeze-ASR-25 q8_0・NVIDIA 顯示卡・已載入」或「SenseVoice-Small・CPU（顯存不足，自動改用）」）、潤飾與中翻英各自實際走的服務與模型（地端 LM Studio＋模型名，或雲端服務名＋模型）、潤飾開關、VRAM 可用量。引擎狀態變化時（`v2c:status` 或設定重新載入事件）自動更新。設定值與實際狀態不同時（例如選 Breeze 但因顯存不足用 SenseVoice）要用一句話說明原因。
  - **UI 細節調整**：同一頁的標籤、提示文字統一用繁中台灣用語；選單選項文字一致（兩處引擎選單同值同文字）；按鈕在處理中時停用並顯示「處理中…」；錯誤訊息用紅色、成功用綠色、說明用灰色小字；窄視窗時欄位換行不溢出。
  - 測試結果以和雲端精靈第 5 步相同的「每一步 ✓／✗＋原因＋延遲」方式呈現。
  - 日誌：只記引擎名稱、耗時、VRAM、錯誤碼。
- 驗收：
  - 在「潤飾與用途」選「地端：Breeze-ASR-25」→ `config.toml` 變成 `route.asr = "local"`、`local.asr = "breeze"`，「地端語音模型」頁同步顯示；從雲端切回地端也正確。
  - 「地端語音模型 → 測試」在有顯存時顯示 Breeze／GPU 與耗時；顯存不足時顯示改用 SenseVoice 與原因。
  - 設定頁沒有 LM Studio 區塊；`config.toml` 的 `[local] llm_*` 保留，選「地端」潤飾時仍走它。
  - 改任何設定都不會立刻寫檔；按「儲存」後 `config.toml` 才變、引擎才重新載入；「取消變更」回到已儲存的值；有未儲存變更時離開會先詢問。
  - 「目前使用中」區塊顯示的引擎與服務和 log 中 `providers for utterance` 一致；顯存不足改用 SenseVoice 時有說明。
  - 新的 Rust 邏輯有單元測試（選單值與設定欄位的對應、`settings_runtime_status` 的內容）。
