# T3.4 Linux 通知提示＋打包

- 波次 / 前置：W14 ／ T3.2、T3.3
- 目標：在 Wayland 以系統通知取代浮動標籤，並提供 .deb／AppImage 的建置方式；交付物放 `releases/` 並附 SHA-256。
- 先讀：`tasks/plan.md` 第 7、9 節；`apps/desktop/src-tauri/tauri.conf.json`；`tools/build-installer.ps1`（流程參考）
- 允許修改：`crates/v2c-platform/src/linux/notify.rs`、`crates/v2c-platform/src/linux/mod.rs`、`crates/v2c-platform/Cargo.toml`、`tools/build-linux.sh`、`docs/linux-setup.md`、`tasks/todo.md`；`apps/desktop` 的 Linux 設定需另外請示
- 對外介面：新增 `linux::notify::{Notifier trait, DbusNotifier}`；不改 `v2c-core`
- 實作重點：
  - 狀態（錄音中、辨識中、完成、錯誤、權限不足）→ 通知內容的純函式；**通知不顯示辨識文字**；同一狀態以 `replaces_id` 更新，不洗版。
  - `DbusNotifier` 走 `org.freedesktop.Notifications.Notify`；測試用 mock，不在測試中真的彈出通知。
  - `tools/build-linux.sh`：檢查依賴（webkit2gtk-4.1、libsoup-3、cmake、clang）→ 缺少就列出 `apt` 指令並結束（**不自動安裝**）→ 建置 → 複製到 `releases/` → 更新 `SHA256SUMS.txt`。
- 驗收（mock）：狀態對應、`replaces_id` 更新、D-Bus 失敗時不讓管線失敗。
- 驗收（本機）：`build-linux.sh` 在本機正確列出缺少的依賴並以非 0 結束；能建置的部分（`v2c-core`／`v2c-platform` 測試）通過。
- 驗證指令：`cargo test -p v2c-platform`；`bash tools/build-linux.sh --check`
- 🧑 需人工：安裝 Tauri Linux 依賴後執行 `tools/build-linux.sh`；實機看通知。
