# T2.6 Android 手機本機語音模型

- 波次 / 前置：W9 ／ T2.1
- 分派：實作 Sonnet（worktree，分支 `t2.6-android-local-model`）→ 測試 Haiku → 審查 Opus → 主 agent 決定（見 `README.md`〈分派流程〉）
- 目標：在手機上離線辨識：sherpa-onnx 官方 Android 支援＋第一次使用時下載的本機模型；並提供比較工具，在你的手機上比較候選模型，作為選預設模型的依據。
- 背景（2026-11-12 你決定）：連不到區網時以系統辨識為主、本機模型為輔，長按小圖示可切換；本機模型也是區網失敗時的備援。沒有設定頁。
- 先讀：`tasks/plan.md` 第 8.1 節；`docs/linux-setup.md`「Linux 建議方案」（SenseVoice 實測數據）；`crates/v2c-asr-local` 的 SenseVoice 實作（只參考參數，不在 Android 重用這個 crate）
- 允許修改：`apps/android/app/src/main/java/**/asr/local/**`、`apps/android/app/src/test/**/asr/local/**`、`apps/android/app/src/debug/**`（比較工具，只在 debug build）、`apps/android/app/build.gradle.kts`（sherpa-onnx 依賴）、`apps/android/app/src/main/jniLibs/**`（如需放預編庫，否則用 AAR）、`docs/android-local-model.md`、`tasks/todo.md`
- 對外介面（Kotlin）：`LocalAsr.isReady()`、`LocalAsr.transcribe(pcm: ShortArray, rate: Int): String`、`LocalModelDownloader`（開始、進度、取消、刪除）、鍵盤用的下載詢問元件。
- 實作重點：
  - 【實作前確認】sherpa-onnx 目前版本的 Android 發佈方式（AAR／預編 `jniLibs`）、Kotlin API、預編庫是否 16 KB 對齊，以及候選模型的名稱、檔案大小、授權、下載網址：
    1. SenseVoice-Small int8（預設候選，約 230 MB）
    2. Paraformer 中英雙語
    3. Whisper small／turbo int8
  - 模型不包進 APK；第一次切到本機模型時，鍵盤顯示一次「下載本機模型（約 N MB）？」；下載到 App 私有目錄，完成後檢查 SHA-256，中斷可重試。
  - 辨識結果交給 FFI `to_zh_tw`（T2.3 未合併前用介面隔開，測試用假的實作）。
  - 比較工具（debug build 限定）：讀取 `adb push` 到 App 目錄的 WAV 與 `.txt` 期望文字，輸出字錯率與延遲表。只記數字，不寫辨識文字到日誌或報告。
- 驗收：單元測試涵蓋下載狀態機（完成、中斷、SHA-256 不符拒用）；飛航模式下按住麥克風能輸入中、英、夾雜句子；比較表寫進 `docs/android-local-model.md`。
- 驗證指令：`cd apps/android && ./gradlew assembleDebug lint testDebugUnitTest`
- 🧑 需人工：在你的手機跑比較工具（用 `tests/fixtures/audio` 的錄音），回報手機型號；依比較表決定預設模型。
- 合併：需你核准（含 🧑）
